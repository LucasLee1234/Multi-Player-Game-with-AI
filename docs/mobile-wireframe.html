Layout decisions and checks

Own route always left; partner hazard layer always right. B's screen reverses the role labels and uses A's layer, not this same data. Keep both boards, room status, signals, public proposals, and Ready visible in one scrolling column on phones.

Desktop keeps this player layout compact with explanatory space beside it; it must never show the other player's undisclosed layer. Use text/symbols as well as shading. Implemented controls must support keyboard focus, labeled buttons, and touch targets; these illustration boxes are not accessibility verification.

Questions for device inspection: Can the player distinguish layers, reach Ready, read both proposals, and understand why arriving alone does not finish? No polished art is needed before these answers.
